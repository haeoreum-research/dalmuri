# [의심구역] 화면 프로그램 7종 — 운영·수정 안내

방탈출 「의심구역」용 화면 프로그램입니다. **인터넷 없이(오프라인) 동작**하며,
HTML 파일을 크롬/엣지에서 열고 **F11 전체화면**으로 운영합니다.

기반 문서: `[의심구역] 프로그램 제작 필요 필수 내용 정리 (0828)_수정 완.pdf`

## 실행 방법

1. 7개 HTML 파일을 `index.html`, `assets/`, `images/`, `videos/` 폴더와 전부 같은 위치에 둡니다.
2. 손님용 PC에서는 진행할 화면의 HTML 파일 하나만 크롬 또는 엣지로 열고 **F11**로 전체화면 전환합니다.
3. 진행자는 `index.html`을 열어 7개 화면으로 바로 이동합니다(`index.html`은 손님 화면에 띄우지 않음).
4. 모든 화면은 인터넷 연결 없이 동작합니다. 예외적으로 4번 화면의 CCTV 1번 칸만 로컬 스트리밍 서버가 필요합니다 (뒤쪽 "4번 화면 CCTV 스트림" 참고).

## 정답과 설정값 수정 위치

1·2·3·4·7번 화면은 `<script>` 앞부분에 **"운영 설정(여기만 수정하면 됩니다)"** 라는 이름의 배너 주석이 있고, 그 안의 값만 바꾸면 됩니다. 5·6번 화면은 이런 통합 배너가 없고 아래처럼 값이 분산되어 있습니다.

- **1번**: `PASSWORD = 'F75R'` / `ITEMS` 배열(비품코드·비품명·보관위치, 현재 33개). ※ `PASSWORD` 입력은 인쇄관리시스템 창이 열려 있을 때만 동작합니다.
- **2번**: `PASSWORD = '1456545'` — 자릿수를 바꾸면 입력 칸 개수도 자동으로 맞춰집니다.
- **3번**: 배너 안 `EMP_ID = '210315'`(실험 종료 사번). **배너 바로 아래에 별도로 선언된** `LOGIN_PASSWORD = '19900410'`(최초 로그인 암호) — 배너 안이 아니라 로그인 처리 코드 근처에 따로 있으니 주의.
- **4번**: 손님용 정답 없음. 배너 안 `CAM1_LIVE`(true/false) / `CAM1_STREAM_URL` / `CAM_LABELS`로 CCTV 구성만 조정.
- **5번**: 통합 배너 없음 — `QUESTIONS` 배열 자체가 설정값입니다. 각 문항은 `image`(이미지 경로) / `heading`(문제 문구) / `choices`(객관식 보기, 비우면 주관식) / `answer`(정답)로 구성됩니다. 주관식 문장형 정답은 오탈자를 어느 정도 허용합니다. 마지막 숨은 글자 연출 내용은 `HIDDEN_WORD` 배열에서 수정합니다.
- **6번**: 통합 배너 없음 — `CORRECT_PW = 'hypnos'`(코드 앞부분의 일반 `var` 선언, 한글 자판 입력값은 `CORRECT_PW_KO`로 별도 인식) / 삭제 진행률 값은 `COUNTDOWN_STEPS` 배열 / 영상 경로는 HTML의 `<video src="videos/camcorder-footage.mp4">`를 직접 수정(파일 상단 주석에도 안내됨).
- **7번**: 손님용 정답 없음. 배너 안 `GRANT_HOLD_MS`로 승인 팝업이 자동으로 닫히는 시간을 조정(0 = 자동으로 닫히지 않고 Esc로만 해제).
- **디자인 전체 수정**: `assets/theme.css` 한 곳을 고치면 7개 화면 모두에 반영됩니다.

## 화면별 진행 순서

**1번 자재보관실** (총 4단계, 코드에 명시된 순서): 1. 데스크탑(초기 화면) → 2. 보안 코드 입력창 → 3. 토너 상태 안내 → 4. 토너 교체 방법(마지막 화면). 바코드 스캔은 이 단계와 별개로 언제든 동작합니다.

**2번 복도 키패드**: 숫자 입력 → 정답 시 ACCESS GRANTED 표시 → 잠금 유지(고정된 다음 단계 없음)

**3번 관찰실** (총 9단계, 코드에 명시된 순서): 1. 로그인 화면 → 2. 부팅 화면 → 3. 데스크탑 → 4. 실험실 제어 프로그램 → 5. 실시간 CCTV 재생 → 6. CCTV 연결 끊김 → 7. 실험 종료 확인 팝업 → 8. 사번 입력 팝업 → 9. 승인 연출·게이트 개방(마지막)

**4번 보안실 시스템 에러** (총 3화면, 진행자가 임의 순서로 전환): 1. 시스템 에러 / 2. 4분할 CCTV / 3. 지정 이미지

**5번 시청각실**: 1~10번 문제를 순서대로 통과 → 숨은 글자 연출(마지막)

**6번 셧다운 USB** (총 5단계, 코드에 명시된 순서): 1. 암호 입력 → 2. 삭제 진행률 표시 → 3. 미확인 기록 발견 경고 카운트다운 → 4. 캠코더 영상 재생 → 5. 완료 화면(마지막)

**7번 안면인식**: 카메라 화면 대기 → (진행자 조작으로) 승인 또는 인식 실패 연출

## 제작진 단축키

**1·3·4·5·6번 화면 공용** (`Ctrl + Shift + Alt`를 함께 누름, 맥은 `Ctrl + Shift + Option`):

| 키 | 동작 |
|---|---|
| P | 단계 이동 패널 열기/닫기 |
| H | 첫 화면으로 |
| J | 이전 단계로 |
| K | 다음 단계로 |
| L | 마지막 화면으로 |
| R | 현재 단계 다시 시작 |
| Esc | (패널이 열려 있을 때만) 패널 닫기 |

패널을 한 번 열어두면(P) 이후에는 화면에 뜬 버튼을 클릭해서 이동할 수도 있습니다. 4번 화면은 추가로 `Ctrl+Shift+Alt+1/2/3`으로 시스템 에러/CCTV/지정 이미지 화면에 바로 진입합니다.

**2·7번 화면 전용** (패널 없이 단일 키로 즉시 연출):

| 화면 | 키 | 동작 |
|---|---|---|
| 2번 | Space | 입력 없이 바로 성공(ACCESS GRANTED) 연출 |
| 2번 | Esc | 입력·성공 상태 초기화 |
| 7번 | Space | 승인 연출 표시 |
| 7번 | X | 인식 실패 연출 표시 |
| 7번 | Esc | 승인·실패 연출 해제 |

## 복구 방법

모든 화면은 진행 상태를 브라우저에 저장하지 않습니다. **F5 새로고침 = 항상 완전 초기화**이며, 다음 손님을 위해 화면을 되돌리는 가장 확실한 방법입니다.

1·3·4·5·6번 화면은 F5 대신 제작진 패널의 **H(첫 화면)** 또는 **R(현재 단계 다시 시작)** 로도 빠르게 되돌릴 수 있습니다.

## 바코드 스캐너 (1번 화면)

USB 바코드 스캐너(키보드 웨지 방식)를 꽂으면 별도 설정 없이 동작합니다.
스캐너가 코드를 입력하고 Enter(또는 Tab)를 보내면 해당 물품 팝업이 뜹니다.
스캐너의 "종료 문자(suffix)"가 Enter로 설정되어 있는지 확인하세요(대부분 기본값).

- **스캐너 없이 테스트**: 키보드로 코드를 치고 Enter — 스캐너가 찍는 것과 동일하게 동작합니다.
- 실물 바코드 라벨에는 비품코드(`DMR-0001` 등)가 Code128 형식으로 인코딩되어야 합니다.

## 안면인식 카메라 (7번 화면)

- 카메라는 브라우저가 "보안 연결(secure context)"로 판단하는 상태에서만 동작합니다. 위 실행 방법대로 크롬/엣지에서 파일을 열어 사용하는 일반적인 경우라면 별도 설정 없이 카메라 권한 팝업에서 **허용**만 누르면 됩니다.
- 카메라를 쓸 수 없는 상태로 판단되면(보안 연결 아님 · 브라우저 미지원 · 권한 거부 · 장치 없음 · 다른 앱에서 사용 중 등) 자동으로 노이즈 화면으로 전환되고, 원인에 맞는 한국어 안내 문구와 함께 화면을 탭하면 재시도하는 버튼이 표시됩니다.
- 주소 끝에 `?debug=1`을 붙여서 열면 좌하단에 실패 원인이 표시됩니다(현장 점검용).
- 카메라가 없거나 연결되지 않아도 노이즈 화면으로 대체되어 진행자 단축키(Space/X/Esc) 연출에는 지장이 없습니다.

## 4번 화면 CCTV 스트림

- 4분할 CCTV 중 **CAM 01(왼쪽 위) 한 칸만** 실제 영상이 나올 수 있고, 나머지 3칸은 항상 NO SIGNAL로 고정되어 있습니다(영상 파일을 넣어도 표시되지 않습니다).
- CAM 01은 영상 파일이 아니라 **MediaMTX WebRTC 스트림**(`CAM1_STREAM_URL`, 기본값 `http://127.0.0.1:8889/osmo...`)을 그대로 가져와 보여줍니다. 이 HTML을 여는 PC에서 MediaMTX 서버가 해당 주소로 실행 중이어야 실제 영상이 나옵니다.
- 라이브 스트림을 쓰지 않으려면 `CAM1_LIVE`를 `false`로 바꾸면 CAM 01도 NO SIGNAL로 고정됩니다.

## 현장 운영 팁

- 크롬 **키오스크 모드**로 띄우면 손님이 빠져나올 수 없습니다:
  `chrome.exe --kiosk "C:\...\1_자재보관실_모니터.html"`
- 4번(시스템 에러)·7번(안면인식)의 진행자 조작은 **무선 키보드/프레젠터**를 연결해 관제실에서 누르는 방식을 권장합니다.
